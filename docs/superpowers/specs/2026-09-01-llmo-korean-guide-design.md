# LLMO 한국어 가이드 아티클 설계

## 목적

`LLMO란 무엇인가` 검색 의도를 만족하는 한국어 롱폼 가이드를 `/lab`에 추가한다. AI 검색에서의 브랜드 언급과 인용을 늘리려는 실무자를 대상으로, 개념 이해부터 실행 체크리스트까지 한 페이지에서 제공한다.

## 메타데이터

- Title: `LLMO란 무엇인가? AI와 대규모 언어 모델을 위한 콘텐츠 최적화 가이드`
- Description: `LLMO의 개념부터 SEO·AEO·GEO와의 차이, AI에 인용되는 콘텐츠의 5가지 조건, 성과 측정 방법, 실전 체크리스트까지 한 번에 정리합니다.`
- Category: `LLMO GUIDE`
- Slug: `what-is-llmo`

## 콘텐츠 구조

1. 히어로: LLMO의 정의와 AI 검색 가시성이라는 핵심 메시지
2. 비교표: SEO, AEO, GEO, LLMO의 초점과 목표, 주요 플랫폼
3. 핵심 원칙: 정보 이득, 엔터티 최적화, 구조화된 의미론적 콘텐츠, 명확성 및 출처 표기, 권위와 언급
4. 성과 측정: 브랜드 언급 빈도, 점유율, 감성과 맥락, AI 추천 유입과 전환, 주제 권위
5. 인컨텍스트 러닝: 원리와 LLMO 전술로서의 한계
6. 실행 체크리스트: 우선순위가 드러나는 16개 항목
7. 결론 및 CTA: GEO Watcher로 AI 가시성을 진단하는 흐름으로 연결

## 구현 범위

- 기존 `/lab/llmo-eeat`의 히어로, 본문, 목차, 모바일 패턴을 재사용한다.
- 새 라우트는 `src/app/lab/what-is-llmo/`에 둔다.
- 목차는 한국어 섹션명을 표시하고 각 본문 섹션 앵커와 일치시킨다.
- 본문 가독성을 위해 기존 `article-*` 클래스와 `--fs-body` 계열 폰트 변수를 사용한다.
- 비교표는 기존 div 기반 `article-table`로 구현하며, 2열 표가 생기면 `article-table--2col` 클래스를 사용한다.
- 24자보다 긴 `article-h2`는 줄바꿈 인라인 스타일을 적용한다.
- `LabArticles.tsx`의 `POSTS`에 새 카드를 추가한다. Featured 섹션의 기존 3개 카드는 변경하지 않는다.
- 새 카드의 날짜는 작업일인 `2026.09.01`로 설정하고, 그리드에서 자동 최신순으로 노출되게 한다.
